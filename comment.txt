Framework ที่ใช้

- Frontend: React 19 + Vite — ยิง request ด้วย fetch() เปล่าๆ (ไม่มี axios) ผ่านตัวช่วยกลาง authFetch() ที่ frontend/src/utils/api.js
- Backend: Express 5 (Node.js) — cookie ทั้งหมดเป็นกลไกของ Express + npm package cookie-parser, ไม่ได้เขียนเองตั้งแต่ต้น

กลไกคุกกี้ทำงานยังไง

1. ฝั่งตั้งค่า (backend/server.js:31)
app.use(cookieParser());
cookie-parser คือ middleware ที่แปลง header Cookie: ที่ browser ส่งมา ให้กลายเป็น object req.cookies ให้เราอ่านง่ายๆ — ถ้าไม่มีบรรทัดนี้ req.cookies จะเป็น undefined เสมอ

2. ตอน login เซ็ตคุกกี้ (backend/routes/auth.js)
const token = jwt.sign(payload, process.env.JWT_SECRET, { expiresIn: '8h' });
res.cookie(AUTH_COOKIE, token, cookieOptions);   // res.cookie() เป็นเมธอดของ Express เอง
res.json({ user: payload });                      // ไม่มี token ปนใน body แล้ว
res.cookie() สั่งให้ Express แปะ header Set-Cookie กลับไปให้ browser — browser เป็นคนเก็บเองอัตโนมัติ ไม่มีโค้ด JS ฝั่งเราไปยุ่งกับมันเลย

3. options ที่ backend/utils/cookieOptions.js แต่ละตัวทำหน้าที่อะไร
